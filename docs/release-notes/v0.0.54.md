# noyalib-serde-yaml 0.0.54

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **In lockstep with noyalib 0.0.54**: the exact core pin moves to `=0.0.54`, so this release picks up every core change for that version.
* **`from_reader` is bounded**: the shim's `from_reader` reads at most one byte past the length limit before failing, instead of buffering the whole source; it is the core's fix, reached through the drop-in.
* **Release gate covers cargo-deny**: a tag is refused while `deny.toml` allows a git source, so the allowance the iteration needs for the core's branch cannot ship.
