# noyalib-serde-yaml 0.0.62

Release date: 2026-11-17. Remaining release-page sections are generated
at release time.

## Highlights ⭐️

* **Closer serde_yaml 0.9 parity**: a root sequence index prints as `.[1]`, and a byte order mark inside plain or block text reads as text, as upstream does.
* **%TAG with a byte order mark is refused**, as libyaml refuses it; before, a tag built from that prefix could not be read back (found by `fuzz_roundtrip`).
* **In lockstep with noyalib 0.0.62**, the family's release after 0.0.60 (v0.0.61 was folded in and never published).
